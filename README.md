# Shortsmith

Make YouTube Shorts (1080 × 1920, 30 fps) from text, code and screenshot scenes, right in your browser. Nothing is uploaded anywhere: the video is drawn on a canvas and recorded locally.

## Run it

You need **Node.js 18 or newer** (https://nodejs.org).

```bash
cd shortsmith
npm install
npm run dev
```

Your browser opens at http://localhost:5173. Use **Chrome or Edge** for the best results (they record MP4 or WebM; Safari records MP4).

To make a production build you can host anywhere:

```bash
npm run build      # output goes to dist/
npm run preview    # serve the build locally
```

## Making a video

1. **Script panel (left):** each card is one scene. Pick its type:
   - **Text**: big animated words. Wrap words in `*stars*` to highlight them.
   - **Code**: paste code, choose the language and file name. It appears in a dark code-editor window with syntax colours, line numbers and a blinking cursor. Tick "Type the code out" for the typing effect.
   - **Terminal**: a terminal window. The command types itself after the prompt, then the output prints line by line. Strings, numbers and errors are coloured automatically.
   - **Screenshot**: upload any image (for example a screenshot of your real VS Code) with an optional caption. It slowly zooms in.
2. Set each scene's length with − / +. The whole Short should stay under 3:00.
3. **Look & sound panel (right):** background, typeface, text animation, size, position, channel handle, an optional background photo, and a safe-zone overlay that shows where YouTube's buttons will cover your video.
4. **Sound:**
   - **Music:** pick a built-in track (Lo-fi, Upbeat or Ambient) or **My file** to use your own MP3/WAV/M4A. The built-in tracks are generated by the app itself, so they are free to use. Only upload music you have the rights to. It loops if it is shorter than the video and fades out at the end.
   - **Sound effects:** typing that follows the code and terminal commands as they type, and a transition sound at each scene change. Upload your own sound for either: for typing, a single key click plays on every letter, and a longer typing recording loops while text types.
   - **Automatic voiceover:** switch on **Voiceover** in a scene card and the app reads that scene's text aloud. Pick the voice and speed under **Voiceover** in the right panel (▶ Try plays a sample). The scene gets longer automatically if the voice needs more time. Use **Say this instead** when the spoken words should differ from the screen, for example `||` → "the or operator". New text scenes have it on by default (you can turn that off). The voices come from the free, open-source Kokoro model, which runs on your own computer: no account, no API key, no cost. The first time, it downloads the model (about 90 MB), so you need internet once; after that it's cached. English voices only.
   - **Your own recording:** click **+ Upload audio** on any scene card to add a voiceover or sound effect. It starts with the scene and replaces the automatic voice. **Fit length to audio** sets the scene length to match it, and the music gets quieter while it plays (you can switch that off).
   - You hear everything while previewing, and the same sound is recorded into the video.
5. Click **Record video**. It plays the whole Short once in real time and records it, so keep the tab open and visible until it finishes.
6. Click **Save video** and upload the file in YouTube Studio.

Your script, settings, uploaded files and generated voiceovers are saved in your browser automatically and come back after a reload. They never leave your computer.

## Project layout

```
src/
  App.jsx                 main app: state, playback, recording
  renderer.js             draws every frame on the canvas (backgrounds, text, code, screenshots)
  audio.js                music tracks, sound effects, scene audio, ducking, audio for recording
  store.js                saves uploaded files and voices in the browser (IndexedDB)
  tts.js, tts.worker.js   automatic voiceovers (Kokoro text-to-speech in a background thread)
  highlight.js            small syntax highlighter + code editor colour theme
  presets.js              backgrounds, fonts, motions, languages, sample project
  components/
    SceneCard.jsx         one scene in the script list
    LookPanel.jsx         style settings
    ResultModal.jsx       preview + save after recording
  styles.css
```

## Ideas for changes

- **New background:** add an entry to `LOOKS` in `src/presets.js`.
- **New language:** add keywords to `KEYWORDS` in `src/highlight.js` and the name to `LANGS` in `presets.js`.
- **Editor colours:** change `EDITOR_THEME` in `src/highlight.js`.
- **New music track:** add an entry to `SONGS` in `src/audio.js` (chords, bass and drums are written in code) and to `MUSIC_TRACKS`.
- **More voices:** add ids to `VOICES` in `src/tts.js` (the full list is on the Kokoro model page).
- **Higher bitrate:** change `videoBitsPerSecond` in `src/App.jsx`.
